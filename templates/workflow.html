EduShield Data Pipeline Flowchart

1
Raw Dataset Ingestion

Initial student cohort data containing 4,424 records and 35 distinct academic and socioeconomic variables is loaded directly from a local CSV file.

2
Data Preprocessing

Null/missing check and duplicate values removal. Targets are mapped from a multi-class status (Dropout, Enrolled, Graduate) into a binary indicator: Dropout (1: At Risk) vs Graduate/Enrolled (0: Safe).

3
Exploratory Data Analysis (EDA)

Data distributions and statistical weights are calculated. Interactive Plotly charts are drawn to identify correlations between debt status, scholarship status, and enrollment demographics.

4
Feature Scaling

Numerical variables are standardized using a StandardScaler to center feature means at 0 and scale variance to 1, preventing high-value parameters from biasing predictions.

5
Train-Test Data Splitting

The cleaned dataset is split into an 80% training set (3,539 records) to train classification models and a 20% test set (885 records) to validate model performance.

6
Train 7 Machine Learning Models

Trains 7 classification algorithms: Logistic Regression, Decision Trees, Random Forest, Support Vector Machines (SVM), K-Nearest Neighbors (KNN), Gradient Boosting, and XGBoost.

7
Model Evaluation Metrics

Calculates Accuracy, Precision, Recall, F1 Score, and ROC-AUC score metrics for each model. Generates confusion matrices and ROC curves using the 20% validation split.

8
Best Model Deployment (XGBoost)

XGBoost achieved the highest F1 score (80.74%) and Accuracy (88.25%). The model parameters are serialized to student_dropout_model.pkl and loaded into the Flask server.

9
Real-Time Risk Prediction

Form parameters submitted by advisors are compiled, scaled, and scored by the active XGBoost model to yield instantaneous student retention probabilities.

10
Targeted Recommendations

Tailors dynamic interventions based on risk classifications (Academic tutoring and aid for High-risk; monthly trackers for Medium-risk; career guidance for Low-risk).
