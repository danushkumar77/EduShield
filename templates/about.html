Project Description

EduShield is an AI-powered student retention analytics platform built to assist academic administrators and student counselors in identifying dropout risks. By modeling historical enrollment profiles using machine learning classifiers, EduShield translates complex demographic, socioeconomic, and curricular factors into actionable probabilities, enabling targeted early intervention.

Developed as a modular, responsive web application, the system integrates data exploration, model validation, and single-student assessment utilities in a unified, production-grade interface.

Core Objectives
Early Warning Alerts

Compute student risk profiles at critical check-points in the first academic year.

Proactive Guidance

Generate recommended academic and financial interventions based on risk severity.

Data-Driven Insights

Empower academic deans with aggregate cohort diagnostics and trend breakdowns.

Machine Learning Algorithms
1. XGBoost Classifier (Deployed)

Gradient boosted decision trees utilizing optimized parallel tree learning. Achieved best F1 Score: 80.74%.

2. Random Forest Classifier

Ensemble bagging classifier constructing multiple decision trees to minimize overfitting variance.

3. Gradient Boosting Classifier

Ensemble model building sequential weak decision trees to minimize calculated log-losses.

4. Logistic Regression

Baseline parametric linear classifier modeling student dropout probabilities using a sigmoid function.

5. Support Vector Machine (SVM)

Maximizes margins between hyperplanes to separate classifications. High precision: 90.65%.

6. K-Nearest Neighbors (KNN)

Non-parametric instance-based classifier grouping student points by Euclidean feature distance proximity.

7. Decision Tree Classifier

Splits nodes based on Information Gain/Gini impurity values to generate interpretable flowchart rules.

Dataset Information

The platform is modeled on the **"Predict Students' Dropout and Academic Success"** dataset, originally compiled by the **UCI Machine Learning Repository** from an administrative student cohort.

Total Records 4,424

System Architecture
1. Client Layer (Presentation) Bootstrap 5 templates with custom responsive glassmorphic CSS rules and Plotly client-side chart drawing.
2. Routing & Controller Layer (Application) Flask app routes handling auth sessions, prediction submissions, and CSV/PDF report downloads.
3. Data & Inference Layer (Analytics) Pandas loads cohort datasets; joblib deserializes fitted standard scalers and XGBoost classifiers for inference.
4. Storage Layer (Persistence) SQLite databases containing `users` and `prediction_history` tables.
