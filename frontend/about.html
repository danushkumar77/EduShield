About EduShield Platform

System Architecture, ML Workflow, and Cloud Deployment

Project Mission

EduShield is an enterprise-grade AI analytics platform engineered to assist academic administrators, institutional deans, and advisors in reducing university dropout rates. By modeling enrollment profiles across 34 feature dimensions, EduShield transforms complex student indicators into interpretable risk probabilities.

The platform operates with a decoupled modern architecture: a high-speed Edge frontend served globally on Vercel, backed by an autonomous Python machine learning service hosted on Render, persisting audit logs in MongoDB Atlas.

Core Objectives
Early Warning Alerts

Detect at-risk students before first-year dropout occurs.

Targeted Interventions

Deliver personalized financial and academic counselling action lists.

Continuous Auditing

Track and export audit logs for compliance and institutional reporting.

Cloud Architecture & Pipeline
Frontend
Vercel Edge Network

Static HTML5/CSS3/JavaScript SPA with sub-second global CDN latency and responsive glassmorphism UI.

ML Backend
Render Cloud Service

Python 3 Flask API with Gunicorn, StandardScaler normalization, and XGBoost inference engine.

Cloud Database
MongoDB Atlas Cluster

AWS Mumbai replica set storing users, analyst sessions, and historical student risk assessments.
